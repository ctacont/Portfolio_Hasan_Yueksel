**[https://hasanyueksel.de](https://hasanyueksel.de)**

## 📋 Über das Projekt

Diese Portfolio-Website präsentiert meine Fähigkeiten, Projekte und Erfahrungen als Full-Stack Entwickler. Die Website wurde vollständig modular aufgebaut mit externen CSS- und JavaScript-Dateien für optimale Wartbarkeit und Performance.

### Hauptfunktionen

- 🎨 **Hero-Slider** mit automatischer Rotation und manueller Navigation
- 📱 **Responsive Design** für alle Bildschirmgrößen
- ✨ **GSAP Animationen** mit ScrollTrigger für smooth Scroll-Effekte
- 🎯 **Interaktive Skill-Karten** mit detaillierten Modal-Ansichten
- 💼 **Projekt-Showcases** mit Hover-Effekten und Links
- 📧 **Kontaktformular** mit moderner UI
- 🌙 **Glassmorphism Design** für moderne Ästhetik

## 🛠️ Technical Stack

### Frontend

- **HTML5** - Semantisches Markup
- **CSS3** - Modular aufgebaute Stylesheets
- **Tailwind CSS v3.x** - Utility-First CSS Framework (CDN)
- **JavaScript ES6+** - Vanilla JavaScript, keine Frameworks
- **GSAP v3.12.2** - Professionelle Animationsbibliothek
  - ScrollTrigger Plugin
  - ScrollToPlugin

### Architektur

**Modulare CSS-Struktur:**
- `fonts.css` - Schriftdefinitionen und Font-Imports
- `variables.css` - CSS Custom Properties und Variablen
- `components.css` - Komponenten-spezifische Styles
- `animations.css` - Animation Definitions und Keyframes
- `utilities.css` - Utility-Klassen
- `layout.css` - Layout und Grid Definitions
- `modals_utility.css` - Modal-spezifische Styles

**Modulare JavaScript-Struktur:**
- `main.js` - GSAP Initialisierung, Scroll-Effekte, Menu-Interaktionen
- `slider.js` - Hero-Slider Funktionalität
- `modals.js` - Modal Open/Close Logik
- `skills-data.js` - Skill-Modal Datenmanagement

## 🚀 Installation & Lokales Setup

1. **Repository klonen:**
```bash
git clone https://github.com/ctacont/Portfolio_Hasan_Yueksel.git
cd Portfolio_Hasan_Yueksel
```

2. **Öffnen:**
Öffne `index.html` in deinem Browser oder verwende einen lokalen Webserver:

```bash
# Mit Python
python -m http.server 8000

# Mit Node.js (http-server)
npx http-server
```

3. **Besuche:** `http://localhost:8000`

## 🎨 Features im Detail

### GSAP Animationen

Die Website nutzt GSAP für flüssige, performante Animationen:
- Scroll-basierte Animationen mit ScrollTrigger
- Smooth Scrolling zu Sektionen
- Parallax-Effekte
- Fade-In Animationen beim Scrollen

### Hero Slider

Automatischer Bild-Slider mit:
- Auto-Play Funktionalität (5 Sekunden Intervall)
- Manuelle Navigation (Vorwärts/Rückwärts)
- Smooth Transitions
- Responsive Design

### Interaktive Skill-Karten

- Hover-Effekte mit Farbwechsel
- Modal-Fenster mit detaillierten Informationen
- Kategorisierte Technologie-Stacks
- Responsive Grid-Layout
